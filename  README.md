Food Delivery Order Processor

A Python-based Food Delivery Order Processing System that calculates order totals, applies discounts, adds delivery charges, handles invalid orders, identifies the highest-value order, and generates a daily sales report.

Features

* Menu management using Python dictionaries.
* Order management using lists and dictionaries.
* Automatic calculation of order totals.
* 10% discount for orders worth Rs. 500 or more.
* Fixed delivery charge of Rs. 40.
* Validation of invalid menu items and quantities.
* Handling of empty orders.
* Identification of the highest-value order.
* Automatic generation of a daily sales report.

Technologies Used

* Python 3
* JSON
* Lists and Dictionaries
* Functions
* Conditional Statements
* File Handling

How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure Python 3 is installed.
4. Run the following command:
python3 food_delivery.py

Sales Report

The program automatically generates a sales_report.txt file containing:

* Total orders processed.
* Total revenue.
* Highest-value order.
* Highest order value.
* Individual order totals.

Sample Results

* Total Revenue: Rs. 4300
* Highest Value Order: 110
